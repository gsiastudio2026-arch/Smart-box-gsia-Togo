🧪 Chimie - Atomes + Équations Bilan Eau & CO2

Tableau Périodique - Clique un atome

Clique sur un atome
H = Hydrogène, Z=1

Équations Bilan Demandées DG

EAU : Formation de l'eau
2H₂ + O₂ → 2H₂O
Réactifs (à gauche): 2 molécules de Dihydrogène (H2) + 1 molécule de Dioxygène (O2)
Produits finis (à droite): 2 molécules d'Eau (H2O)
Équilibrage: 4 atomes H et 2 atomes O de chaque côté
DIOXYDE DE CARBONE : Combustion carbone
C + O₂ → CO₂
Réactifs: 1 atome de Carbone (C) + 1 molécule Dioxygène (O2)
Produits finis: 1 molécule de Dioxyde de carbone (CO2)
Type: Combustion complète - Déjà équilibré
Autre exemple : Formation Rouille
4Fe + 3O₂ → 2Fe₂O₃
Réactifs: Fer + Oxygène | Produit: Oxyde de fer (rouille)

L'IA explique - Chimie

Équation bilan = recette de cuisine. On compte les atomes à gauche (réactifs) et à droite (produits). Le nombre doit être égal. On ajoute des coefficients : 2H2 + O2 → 2H2O.

📏 FORMULES CHIMIQUES - Alcanes, Saponification, Estérification

1. ALCANES - Formule générale CnH2n+2

FORMULE GENERALE : CnH2n+2
n=1 Méthane: CH₄ → Gaz cuisine
Équation combustion: CH₄ + 2O₂ → CO₂ + 2H₂O

n=2 Éthane: C₂H₆ → CH₃-CH₃
n=3 Propane: C₃H₈ → CH₃-CH₂-CH₃ (gaz)
n=4 Butane: C₄H₁₀ → CH₃-CH₂-CH₂-CH₃ (briquet)

Réactifs combustion alcane: Alcane + O2
Produits finis: CO2 + H2O
Exemple: C₄H₁₀ + 13/2 O₂ → 4CO₂ + 5H₂O

2. SAPONIFICATION - Fabrication du savon au village

CORPS GRAS + SOUDE → GLYCEROL + SAVON
Équation Bilan Générale:
(R-COO)₃C₃H₅ + 3 NaOH → C₃H₈O₃ + 3 R-COONa

Réactifs (gauche):
• Triglycéride (Huile de palme/palmiste) : (C₁₇H₃₅COO)₃C₃H₅
• Soude caustique : 3 NaOH (hydroxyde de sodium)

Produits finis (droite):
• Glycérol : C₃H₈O₃ (glycérine, adoucit peau)
• Savon : 3 C₁₇H₃₅COONa (palmitate de sodium)

Exemple concret Togo:
Huile de palme + NaOH → Savon dur + Glycérol
C'est une hydrolyse basique d'un ester.

3. ESTERIFICATION - Parfum / Arôme fruité

ACIDE + ALCOOL ⇌ ESTER + EAU (Réversible)
Équation Bilan Générale:
R-COOH + R'-OH ⇌ R-COOR' + H₂O

Réactifs (gauche):
• Acide carboxylique : R-COOH (ex: CH₃COOH acide acétique = vinaigre)
• Alcool : R'-OH (ex: C₂H₅OH éthanol)

Produits finis (droite):
• Ester : R-COOR' (odeur fruitée, parfum)
• Eau : H₂O

Exemple concret équilibré:
CH₃COOH + C₂H₅OH ⇌ CH₃COOC₂H₅ + H₂O
Acide acétique + Éthanol ⇌ Éthanoate d'éthyle (odeur vernis à ongle / poire) + Eau

Réaction inverse = Hydrolyse de l'ester

L'IA explique - Formules Chimie

Alcanes = carburant CnH2n+2. Saponification = huile + soude = savon + glycérol (comme au village). Estérification = acide + alcool = parfum + eau. C'est réversible.
